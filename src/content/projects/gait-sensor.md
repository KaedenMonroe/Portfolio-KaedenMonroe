As an undergraduate researcher in the Neuromuscular Biomechanics Lab, I worked on wearable mobility monitoring using insole-based force sensors. My primary contribution was building MATLAB signal processing routines, peak detection and time-series segmentation, to extract usable gait metrics from raw force-trial data across a large number of trials.

Beyond signal extraction, I performed process mapping and time-series analysis to identify critical gait phases, applying methodologies borrowed from Industrial Engineering time studies to establish performance baselines for the lab's mobility monitoring work.

I partnered closely with graduate researchers to refine mobile app prototypes built on top of this data, incorporating stakeholder feedback to improve real-time usability. The project concluded with a co-authored internal poster presenting the signal processing methodology and wearable monitoring status to the broader lab.
